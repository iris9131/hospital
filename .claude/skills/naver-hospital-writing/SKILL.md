# 네이버 병원 글 수집

목표: 원장이 1인칭으로 직접 쓴 것처럼 읽히는, 잘 쓴 병원 글을 네이버 블로그에서 찾아
`naver-collection/posts.json` 에 쌓는다. 기준 예시는 https://blog.naver.com/seoulclear_busan/224289640077 이다.

인자로 과목이 오면 그 과목부터 한다. 인자가 없으면 **성형외과 → 피부과 → 기타 과목** 순서로 한다.

## 0. 준비 확인 (처음 한 번)

1. `aside --version` 이 동작하고 Aside 앱이 켜져 있으며 네이버에 로그인돼 있어야 한다.
2. sns 스킬이 있어야 한다 (`~/.claude/skills/sns` 또는 `.claude/skills/sns`). 없으면 사용자에게
   `npx skills add tjdwls101010/Agentic-SNS` 를 안내하고 멈춘다.
3. 명령은 sns 스킬의 규칙대로 실행한다:
   `uv run "<sns 스킬 경로>/scripts/cli.py" naver-blog <command> …` 를 한 번에 하나씩.
   명령별 옵션은 `naver-blog search --help`, `naver-blog post --help` 로 확인한다.
4. 체크포인트·캡차·잠금이 뜨면 즉시 멈추고 사용자에게 알린다. 우회하지 않는다.

## 1. 검색

과목마다 아래 검색어를 돌린다(`naver-blog search "<검색어>" --limit 20 --json`). 관련도순(sim)으로
한 번 돌리고, 결과가 적거나 오래된 글뿐이면 `--sort date` 로 한 번 더 돌린다.

공통 검색어 틀 (`{과}` 자리에 성형외과, 피부과, 치과, 한의원, 정형외과, 소아청소년과, 안과 등을 넣는다):

- 원장소개: `{과} 원장입니다`, `{과} 대표원장 인사`, `{과} 원장 소개 이력`, `{과} 원장 이야기`
- 철학: `{과} 진료 철학`, `{과} 진료 원칙`, `{과} 수술 철학`, `{과} 과잉진료 하지 않는`, `{과} 권하지 않는 이유`
- 브랜딩: `{과} 병원 이름 의미`, `{과} 브랜드 스토리`, `{과} 개원 이야기`, `{과} 개원 준비 원장`, `{과} 인테리어 철학`
- 공지: `{과} 개원 안내 원장`, `{과} 휴진 안내 원장`, `{과} 이전 확장 안내`, `{과} 새해 인사 원장`, `{과} 감사 인사 환자분들께`

성형외과 추가: `성형외과 상담 원칙 원장`, `성형외과 재수술 원장 생각`, `성형외과 자연스러움 원장`, `성형외과 수술 거절`
피부과 추가: `피부과 시술 권하지 않는`, `피부과 전문의 원장 생각`, `피부과 원장 칼럼`, `피부과 장비 고르는 기준 원장`

## 2. 후보 거르기 (본문 읽기 전)

남긴다:
- 병원 공식 블로그로 보이는 곳(블로그 이름이나 글에 병원명·원장명이 있음)
- 제목·요약에 원장 1인칭이나 병원의 결정·원칙·이야기가 보이는 글

버린다:
- 체험단·협찬·내돈내산 후기, 일반인 리뷰
- 가격·이벤트 홍보, 시술 전후 사진 위주 글
- 대행사가 쓴 듯한 키워드 반복 정보성 글("○○역 피부과 추천" 류)
- 이미 posts.json 에 있는 URL (중복)

## 3. 본문 읽고 평가

후보마다 `naver-blog post <url>` 로 본문을 읽는다. 아래 세 항목을 1~5점으로 매긴다.

- **진정성(authenticity)**: 원장이 직접 쓴 목소리인가, 개인 경험·계기가 있는가
- **구체성(specificity)**: 숫자, 기준, 실제 장면, "하지 않는 것"이 구체적인가
- **문장력(voice)**: 읽히는가, 기억에 남는 문장이 있는가, 과장·상투어가 적은가

합계 11점 이상이면 `status: "picked"`, 8~10점은 `"candidate"`, 그 아래는 기록하지 않는다.

## 4. posts.json 에 쓰기

`naver-collection/posts.json` 의 `posts` 배열에 추가하고 `updated` 를 오늘 날짜로 바꾼다.
URL 기준으로 중복을 막는다. 필드:

```json
{
  "url": "https://blog.naver.com/<blogId>/<logNo>",
  "blog_id": "<blogId>",
  "hospital": "병원명",
  "dept": "성형외과 | 피부과 | 치과 | 한의원 | 정형외과 | 소아청소년과 | 안과 | 기타",
  "type": "공지 | 원장소개 | 철학 | 브랜딩",
  "title": "글 제목 그대로",
  "date": "YYYY-MM-DD",
  "summary": "무슨 글인지 1~2문장",
  "structure": ["도입: …", "본문: …", "마무리: …"],
  "quotes": ["본문에서 그대로 옮긴 짧은 문장 1~3개"],
  "why_good": "왜 잘 썼는지 한두 문장 (따라 쓸 포인트)",
  "caution": "의료광고 심의상 조심할 표현이 있으면 적는다, 없으면 빈 문자열",
  "scores": { "authenticity": 0, "specificity": 0, "voice": 0 },
  "status": "picked | candidate"
}
```

규칙:
- `quotes` 는 본문에 실제로 있는 문장만, 한 문장씩 짧게. 지어내거나 고쳐 쓰지 않는다.
  본문 전체를 옮기지 않는다(저작권). 요약과 짧은 인용만 남긴다.
- 확인 못 한 값(날짜 등)은 빈 문자열로 둔다.
- 과목당 picked 20편 이상을 목표로 한다. 다 채우지 못하면 몇 편을 읽었고 몇 편을 골랐는지 보고한다.

## 5. 마무리

- 과목별·유형별로 picked / candidate 개수를 표로 보고한다.
- 특히 좋은 글 5편을 골라 한 줄씩 이유와 함께 알려준다.
- 모아보기 페이지는 `python3 -m http.server 8000 -d naver-collection` 후 http://localhost:8000 에서 본다고 안내한다.
- 사용자가 원하면 posts.json 을 커밋하고 push 한다(클라우드 세션에서 링크 페이지로 올릴 수 있게).
